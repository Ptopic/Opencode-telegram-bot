## Error Log Format

All provider errors follow this format:

```
[{ProviderName}] {BatchContext} failed ({attempt}/{maxRetries}): {errorMessage}
[{ProviderName}] {Action} waiting {delay}ms before retry...
```

### Example
```
[JinaEmbedder] Batch 3/5 failed (attempt 4/5): HTTP 429: Rate limit exceeded. Try again in 2000ms.
[JinaEmbedder] Rate limit error on batch 3/5, attempt 4/5. Waiting 2500ms...
```

**Verification**: ✅ PASS
- Provider name included
- Batch number and attempt count included
- Error message preserved
- Delay before retry shown

## Graceful Degradation Chain

```
Primary:   Jina AI (jina-embeddings-v3) → on failure:
Fallback1: Voyage AI (voyage-code-2) → on failure:
Fallback2: OpenAI (text-embedding-3-large) → on failure:
Fallback3: Local (TF-IDF hash vectors) → on failure:
Final:     THROW ERROR — never return silent empty results
```
