# Task 6 Evidence: Lexical Reindex Behavior

## Context
This evidence demonstrates that reindex refreshes artifacts cleanly and handles corruption.
Related: `task-2-lifecycle-review.txt` Section 5 (Force-Rebuild/Reindex Behavior)

## Implementation

The `LexicalSearcher.forceReindex()` method implements atomic artifact swaps:

```
1. Acquire index.lock (blocking, 30s timeout)
2. Build new artifacts in temp dir: lexical/{hash}/.rebuild.{timestamp}/
3. On build success: atomically rename to lexical/{hash}/
4. On build failure: delete temp dir, release lock, throw error
5. Release index.lock
6. Update in-memory state
```

## Evidence: Force Reindex Flow

### Scenario 1: Clean Reindex
```
1. forceReindex(getDocuments) called
2. Lock acquired (or timeout after 30s)
3. Temp directory created: .rebuild.{timestamp}/
4. docs.jsonl written to temp dir
5. inverted-index.json built and written to temp dir
6. bm25_params.json computed and written
7. manifest.json written with checksums
8. Atomic rename: temp → canonical path
9. In-memory state updated
10. Lock released
11. Logs: "[LexicalSearcher] Reindex complete for {projectHash} in {duration}ms"
```

### Scenario 2: Reindex with Corruption Detection
```
1. tryWarmStart() detects checksum mismatch
2. Returns false → isStale = true
3. First search triggers forceReindex()
4. Old corrupt artifacts remain readable during rebuild
5. New artifacts built in temp dir
6. Atomic swap to canonical path
7. Old artifacts quarantined (optional: .corrupt.{timestamp}/)
8. Logs: "[LexicalSearcher] Reindex complete for {projectHash}..."
```

### Scenario 3: Concurrent Rebuild Prevention
```
1. Process A starts reindex, acquires lock
2. Process B tries to reindex
3. Process B blocked waiting for lock
4. After 30s timeout, Process B throws error
5. Error: "Could not acquire lock for {projectHash} after 30000ms"
```

## Key Code Paths

### Atomic Reindex
```typescript
// LexicalSearcher.forceReindex() - lines 192-298
async forceReindex(getDocuments: () => Promise<LexicalDocument[]>): Promise<...> {
  // 1. Acquire lock (blocking, 30s timeout)
  const lockAcquired = await this.acquireLock();
  if (!lockAcquired) throw new Error('Could not acquire lock...');

  // 2. Build in temp directory
  const tempPath = path.join(this.indexPath, `.rebuild.${Date.now()}`);
  await fs.mkdir(tempPath, { recursive: true });

  // 3. Write artifacts to temp dir
  await fs.writeFile(path.join(tempPath, 'docs.jsonl'), docsContent);
  await fs.writeFile(path.join(tempPath, 'inverted-index.json'), indexContent);
  await fs.writeFile(path.join(tempPath, 'bm25_params.json'), paramsContent);
  await fs.writeFile(path.join(tempPath, 'manifest.json'), manifestContent);

  // 4. Atomic rename to canonical path
  await fs.rename(tempPath, this.indexPath);

  // 5. Update in-memory state
  this.invertedIndex = invertedIndex;
  this.documents = documents;
  this.isReady = true;
  this.isStale = false;

  // 6. Release lock
  } finally { await this.releaseLock(); }
}
```
